# `asciirogue` — SPEC.md

> 한국어 TUI 로그라이키 던전 크롤러 (Rust, half-block 비주얼)

---

## 1. 컨셉 & 핵심 가치

**한 줄**: *Brogue + Slay-the-Spire의 만남, 한국어 우선, 텍스트 터미널에서 절반블록 픽셀로 6×4 절차 던전.*

### 왜 만들까
- **Rust 학습**: ECS, async, procgen, WASM의 작은 결을 TUI 게임 한 번에 덮음
- **한국어 TUI 게임 부재**: 기존 로그라이키는 다 영어/일본어
- **end_of_eden 한국어화 fork와 시너지**: 같은 결의 TUI 게임 한국어 UX 노하우 재활용
- **half-block 미적**: 빽빽한 픽셀 대신 2배 높이의 텍스트 셀로 묘사 — 브라우드웨이/코그마인드 류

### 비목표
- 멀티플레이어, 네트워크 (싱글플레이 only)
- RPG 노벨급 스토리 (분위기만 살림)
- HD 그래픽 (텍스트 100% — pure TUI)
- 모바일 (데스크탑/원격 터미널)

## 2. 비주얼 시스템

### 전체 팔레트 (단일 `palettes.toml`)

```toml
# wall: 4-direction 인접에 따라 9가지 모양 (RLTK chapter 16 알고리즘)
[wall]
edge_top  = "▀"   # rgb(160,160,180) 밝은 회색
edge_bot  = "▄"   # rgb(120,120,140) 중간
body      = "█"   # rgb(140,140,160)
corner_NW = "▘"   NE="▝" SW="▖" SE="▗"
h_line    = "▔"   v_line="▏"

[floor]
main      = "░"   # 어두운 갈색 (탐험 경로)
alt       = "·"   # 빈 셀 (대각 시야)
highlight = "▒"   # 보물 근처 (FOV 가장자리)

[entity]
@_player  = "◉"   # gold
g_goblin  = "g"   # magenta
r_rat     = "r"   # pink
T_troll   = "T"   # red
D_dragon  = "D"   # bright red (boss)
S_snake   = "s"   # green
U_undead  = "U"   # gray
W_wraith  = "W"   # white
$^_gold   = "$"   # yellow
!_potion  = "!"   # mint
=_trap    = "^"   # brown
=_chest   = "="   # gold/dark
>_stairs  = ">"   # white
+_door    = "+"   # amber
```

### 글리프 매핑 규칙
- **벽**: RLTK 챕터 16 `wall_glyph()` 4-bit 마스크 차용
- **바닥**: `·` (어두움) ↔ `░` (가장자리) — 시야 가장자리는 점진적으로 `·`로 페이드
- **엔티티**: 단일 문자 (플레이어만 `◉` 2×2 강조 — half-block 결의 가장 큰 강조점)
- **아이템**: `$`, `!`, `=` 등 단일문자 + 색상으로 종류 구분

|---|---|---|---|---|---|

### 스탯 (5종)

- **STR** (근력) — 물리 데미지 + 격파

- **INT** (지능) — 주문력 + MP 회복
- **WIS** (지혜) — FOV + 시야 보너스
- **CON** (체질) — HP + 식량/독 저항

각 8~14 시작값, 합 50 고정. 레벨업 시 (레벨-1) × 6 점을 자유 분배.

## 4. 전투 시스템

### 모델: **턴제 + 에너지 큐 (energy-based turn)**
- 각 엔티티(플레이어 + 적)는 속도 에너지 누적, 100 도달 시 행동 1회
- 플레이어 기본 100/턴 → 항상 1번 행동
- 빠른 적은 80/턴 → 평균 1.25번/플레이어 턴
- 슬라임은 50/턴 → 평균 절반속도

### 액션 4종
1. **이동** (1 칸) — 사방 또는 대각, 가만히 있기로 25% 회피
2. **공격** (인접) — 명중 굴림: `(DEX_w + STR_e) + d100 > 적 회피 + DEX_e`
3. **주문 시전** (1~3 MP) — 학문별 쿨다운
4. **사용** (물약/유물) — 인벤토리 소모

### 데미지 공식
```
물리: MAX(1, STR + 무기 + d<STR> - 방어력/2)
주문: MAX(2, INT + 주문 + d<INT> - 저항)
치명타: 자연 95+ → 2.5배
```

### 상태이상 5종 (도트 데미지 또는 능력 봉인)

| 상태 | 효과 | 출처 | 해제 |
|---|---|---|---|
| 독 | 1~3 매 턴, 5~10턴 | 슬라임, 독 항아리 | 물약 |
| 화상 | 3~6 매 턴, 3~6턴 | 화염 주문, 드래곤 | 물약 |
| 둔화 | 속도 50%, 5~10턴 | 거미, 빙결 | 식량 |
| 침묵 | MP 주문 봉인, 5~8턴 | 언데드 가스 | 턴 |
| 출혈 | 받을 데미지 +1 | 도적 특수 | 붕대 |

## 5. 스킬 트리 (능력 매트릭스)

각 클래스당 **3×3 마법진** (학문 3 카테고리 × 칸 9개). SP 1점당 1칸 활성화.

```text
예: 검투사
                    ↗ 격파 (강타)   ↘ 보루 (디버프 회수)   ↘ 광전사
                  ↗               ↘
   1단  ────  ↗  삼단 베기 ───  황혼 강타
                ↘                ↘
                  ↘ 보루 (방어)   ↘ 광전사 (연속)
                  ↘                ↘
                    ↗ 돌진 (이동)   ↘ 마지막 전사 (HP<10% 데미지 2배)
                  ↗
   2단  ────  ↗  포위 (넉백)     ↘ 
```

### 클래스별 학문

| 클래스 | 학문 1 | 학문 2 | 학문 3 |
|---|---|---|---|
| 검투사 | 강타 | 방어 | 돌진 |
| 도적 | 기습 | 후크 (목표 이동) | 독수리 (원거리 강타) |
| 마법사 | 화염 | 빙결 | 격류 (HP->MP 전환) |
| 사냥꾼 | 사격 | 표식 | 연발 |
| 연금술사 | 시약 | 폭약 | 변환 |

총 9 × 5 = 45 능력치. 각 학문당 9개 스킬 → **45 스킬 POOL**.

## 7. 던전 구조

### 알고리즘: **BSP + 절차적 변주**

- 한 층 = 1 브랜치 BSP 트리 (60×30 평균)
- 룸 4~8개 + 연결 복도 1~3개
- 사이클 룸 (고리) — 7층마다 1회
- 출현 결정성: `(층, 시드)` 해시

### 층별 환경 (1~28)

| 층대 | 환경 | 메커니즘 |
|---|---|---|
| 1-4 | 동굴 | 시야 8, 통상 |
| 5-8 | 카타콤 | 통행 시 마법 + 1 |
| 9-12 | 정원 (오염) | 식량 누적, 돼지 출현 |
| 13-16 | 도서관 | 주문 발견 확률 + |
| 17-20 | 대장간 | 장비 강화 점수 + |
| 21-24 | 신전 (점령) | 표식/함정 + |
| 25-27 | 마지막 (The Maw) | 시야 -2, 식량 없음 |
| 28 | **쏠쏠리의 방** | 보스 + 마무리 + 메타 |

### 특수 룸 (10% 확률/층)

- **보물 룸**: 1~3 보물, 1 트랩, 1 잠금 문
- **신전 룸**: 신전 4종 (치료 식량 / MP 회복 / 능력 메모라이즈 / 깨달음 — 주문 +1)
- **연습 룸**: 훈련 봇 (공격 안함), 자동사냥 가능
- **식당**: 즉시 식량 +8
- **빈 룸**: 함정 1~2 + 숨은 아이템
- **소굴**: 같은 적 3~5 마리 (보스 후보 드롭)

## 8. 아이템 시스템

### 5 카테고리

1. **무기** (30+) — 단검/검/도끼/창/활/석궁/스태프/완드
2. **방어** (20+) — 로브/갑옷/방패/외투
3. **물약** (8) — 치유/마나/해독/소생/치유+(전체-25)/재생(매 턴)/정화/미궁(층 워프)
4. **유물** (20+, meta-relic) — 인챈트 1~3 (예: `+데미지`, `+HP`, `+시야`, `+반사`, `-함정확률`)
5. **창고** — 식량 (몸단위), 금화 (점수)

### 인챈트 시스템 (RNG-dist)
- **30 어픽스**(예: `of_sharpness`, `of_thorns`, `of_zephyr`) x **3 등급**(normal/rare/legendary) = 90 인챈트
- `weapon + "of_sharpness_rare"` = 단검+공격력+5 +DEX+1

## 9. 메타 진행 (영구화)

### 챔피언 영혼 시스템 (Slay-the-Spire 류)

- 한 게임 종료 시 **챔피언 카드** 1~3장 해금
- 챔피언 = 시작 시 부업 1개 보너스 (예: "마법사 +시작 물약 1", "검투사 +시작 식량 +3")
- 챔피언은 5종족 × 5직업 × 3 = 75 조합. 메타 진행으로 75 / 30장 분까지 달성하면 게임 클리어

### 메타 점수

```
score = (층 × 100) + (남은 HP × 10) + (금화 × 1) + (유물 × 250) + (챔피언 × 1000)
```

### 기록/통계
- 한 클래스당 첫 클리어 → 메모리얼 데이터 누적
- 로그 `/Users/mac/.local/share/asciirogue/saves/*.ron` (RON 직렬화)
- 통계 `/Users/mac/.local/share/asciirogue/stats.toml`

## 17. 🌀 회차 누적 적 강화 — "Bolrun" 시스템

> 매 런(회차)마다 적들이 조금씩 강해짐. 죽음/승리 횟수에 비례.

### 곡선 (볼드런 레벨 N=0,1,2,...)

```
            strength
              ↑
    1.6 ─    ╱─ ─ ╲ ─ ─ ─ ─ ─ ─ ─ ─   N=10~15 정점
              │    ╲ ╱
    1.2 ─    ╱      │
              │     │
    1.0 ─   │      │  ← N=0 (첫 런)
              │     ╲
    0.8 ─    ╱       ╲ ─ ─ ─ ─ ─ ─  N=20+ 정점(완만)
              │
    └──────┴───────┴───────── N (회차)
         5     10   15    20+
```

**중요**: 단조 증가 X. **사용자가 게임 디자인에 익숙해지면 강해져야 함**, 따라서 보스 후반에 정점 → 후기는 완만.

### 적용 — 모든 적에 동일 곡선이 아니라 **층대별 분리**

```rust
fn difficulty(n: usize, depth: usize) -> f32 {
    let tier = (depth / 8) as f32; // 1~3 (8층 단위)
    let curve = match tier {
        _ if n < 5 => 1.0 + (n as f32 * 0.05),           // 0~5: 5%/런
        _ if n < 10 => 1.25 + ((n as f32 - 5.0) * 0.04),  // 5~10: 4%/런
        _ => 1.45 + ((n as f32 - 10.0).max(0.0) * 0.005), // 10+: 정점 0.5%/런
    };
    curve
}
```

| 층대 | N=0 | N=5 | N=10 | N=20 | N=40 |
|---|---:|---:|---:|---:|---:|
| 1-8 (동굴) | 1.00 | 1.25 | 1.42 | 1.46 | 1.49 |
| 9-16 (카타콤) | 1.00 | 1.25 | 1.45 | 1.50 | 1.55 |
| 17-24 (신전) | 1.00 | 1.25 | 1.50 | 1.55 | 1.60 |
| 25-28 (쏠쏠리) | 1.00 | 1.25 | 1.50 | 1.58 | 1.65 |

### 적용 대상 (분리)

- **HP**: `적.base_hp * curve(n, depth)`
- **공격**: `적.base_atk * curve(n, depth)`
- **드롭**: 보상 100%, **적 회수 (drop rate)**: `min(200%, 100% + curve * 0.3)` — 적 강해지면 드롭도 보너스
- **경험치**: `100%` 고정 (영구화 떼와 충돌 방지)

### 안전한 보정

- **첫 10회 미만의 플레이어**(N<10)는 헷갈리지 않게 정점 곡선, 곧 사그라짐
- **드롭 보장 모드** (메뉴 토글) — 첫 5회 차에 한해 자동 ON
- **불가능 회차**: curve ≥ 2.0 일 때는 코스모 조정 (보스전 QTE 시간 -10%)

### 메모리/UI 표기
- 메인 메뉴 첫 화면에 현재 N값 표시 ("쏠쏠리 12회 — 카타콤 곰이 1.50배 강함" 식)
- 사망 시 화면에 "다음 런은 [제안된 적 +HP%] — Mute 토글/임계 조정" 표시

## 18. 👻 영혼 누적 환생 보너스 — "Soul Remembrance"

> 죽음 시 영혼을 일부 남김. 다음 생에서 그 영혼이 주인공과 함께.

### 영혼의 출처

#### A. 챔피언 영혼 (1차 — Spec §9)
- 런 종료 시 챔피언 카드 1~3장 해금
- 다음 런 시작 시 부업 1개 영구 사용 (예: "검투사 +시작 식량 +3")
- **쌓이지 않음** (1번 언락 후 새 직업/종족 조합마다 재언락)

#### B. **강령 파편** (Wisp of Will, 2차)
- 런 종료 후 **점수 점유치에 비례**하여 강령 파편 획득
- 강령 파편 = 다음 런의 **장비 슬롯** 1~3
- 누적 가능, 런마다 1~3 선택 (득실)
- 예: 1회 클리어 → 강령 파편 +1, 30층 런 → +5

#### C. **순교자 표시** (Mark of the Departed, 3차 — 가장 강력)
- 보스 처치한 횟수마다 **순교자 표시** +1
- 표시 1개당 다음 런의 **보스 전(Hex 속성)** 약화: 보스 HP -1%, 약점 +1
- 누적: 표시 N개 → 다음 런 보스 전 N% 약화

#### D. **말년의 재물** (Last-Wager, 4차 — 기록)
- 런 종료 시 "말년" — 남은 골드의 10%를 **연금**으로 적립
- 다음 런 시작 골드 +연금 (10% cap, 누적 200 골드 한도)

#### E. **증언** (Deposition, 5차 — 서사)
- 보스 처치마다 증언 1줄 (영구 보관)
- 메뉴에서 "증언의 서" — 게임 내 서사 묶음
- 자신의 챔피언 영혼에 대한 짧은 일기 같은 짧은 텍스트

### 보너스 시스템 트리

```
                           ┌── 챔피언 영혼 (영구 잠금 해제)
                           │
┌── 1차 종료 ──┐             ├── 강령 파편 (장비 슬롯)
│                     │             │
│  다음 런 ────┤  ────  ├── 순교자 표시 (보스 약화)
│                     │             │
└── 4차 종료 ──┘             ├── 말년 재물 (연금)
                           │
                           └── 증언 (서사)
```

### 보너스 적용 우선순위 (한 화면 GUI)

런 시작 시 메뉴에서:
1. 챔피언 카드 선택 (보유한 것 중)
2. 강령 파편 1~3개 → 장비 슬롯에 미리 배치
3. 자동 — 순교자 표시 + 말년

### 보너스 캡 (안 무한 증가)

| 보너스 | 최대 cap |
|---|---|
| 챔피언 카드 | 30개 (75조합 중 30) |
| 강령 파편 | 8개 (장비 슬롯 8 cap) |
| 순교자 표시 | 50개 (보스 -50% cap) |
| 말년 재물 | 200 골드 |
| 증언 | 무제한 (서사용) |

### 인터랙션 (한 가지 예시)

| 현재 | 다음 런 |
|---|---|
| **챔피언: 마법사 +시작 물약 1** | 시작 인벤토리 = [치유 물약 × 1, …] |
| **강령 파편 × 2** | 장비 슬롯 12개 → 14개 |
| **순교자 표시 × 4** | 보스 HP 96%, 약점 1 노출 |
| **말년 재물 +84** | 시작 골드 84 |

→ 1, 2, 3번 모두 **회차 반복 요소를 누적 방향으로 끌어냄**, 한 화면에서 자기 상태 확인 가능.

## 19. 🤖 자동 진행 (Auto-Pilot) — 핵심 신규 차별점

> 게임이 알아서 진행되고, 플레이어는 **필요할 때만** 개입한다. 멀티태스킹 친화.

### 왜 필요?
- **TUI 환경**: 같은 화면 보고 있을 때 다른 작업을 해도 게임은 진행 → 사용자 시간 효율 ↑
- **저사용 시간 활용**: 한 30분 회의 동안 던전 5층 클리어 → 게임 디자인 자연스러움
- **휴식 가능성**: TUI 게임의 피로감 ↓. 게임이 너무 빡빡하면 자동모드가 호흡 정리
- **Roguelike의 "관찰 = 플레이" 결**: 플레이어 캐릭터가 알아서 싸우는 걸 보면서 **판단**은 플레이어가. 카드게임 + 자동 배틀의 합성.

### 모드 3종

| 모드 | 동작 | 키 기본값 |
|---|---|---|
| **수동 (Manual)** | 플레이어가 매 턴 입력 | `m` |
| **반자동 (Semi-Auto)** | 디폴트 자동, 이벤트/임계상황에서 멈춤 | `s` |
| **풀자동 (Full-Auto)** | 1ms 게임 안 멈춤, **결정 포인트만 멈춤** | `f` |

전환은 **언제나** `m`/`s`/`f` 한 글자.

### 페르소나 (성향) — 자동 행동 결정 트리

런 시작 시 한 가지 페르소나 선택, 런 중 변경 가능 (10 MP / 회).

| 페르소나 | 우선순위 규칙 |
|---|---|
| **무적 (Berserker)** | ① 가장 가까운 적 이동 ② 도달 가능 시 공격 ③ HP 30% 미만이면 회복 |
| **기습자 (Striker)** | ① 가장 약한 적 ② 단검 가능시 기습 ③ HP 50% 미만 회복 |
| **연금술 (Alchemist)** | ① HP/MP 70%+ 유지 ② 가장 가까운 적 화염 주문 ③ 식량 5개 미만 회복 |
| **순찰자 (Warden)** | ① 미발견 적 시야 외곽 순찰 ② 물약 0개 시 회복 우선 ③ 그 외 공격 |
| **수호자 (Bulwark)** | ① 가장 가까운 적 ② 방패 가능시 방어 ③ HP 40% 회복 |
| **마법사 (Arcanist)** | ① 가장 가까운 적 ② MP 30%+ 시 주문 ③ 그 외 근접 |
| **사냥꾼 (Trapper)** | ① 함정 탐지 우선 ② 시야 최대화 (탐색) ③ 원거리 우선 |
| **신비 (Mystic)** | ① MP 항상 충전 회복 ② 가장 가까운 적 ③ 주문 우선 |
| **달인 (Hedger)** | 균형 — ① 도달 가능 적 공격 ② 회복 임계 ③ 자원 보존 |

### 자동 멈춤 트리거 (모든 모드 공통)

자동모드도 **다음 상황에서 멈추고 입력 대기**:

1. **임계 이벤트** — HP ≤ 30%, MP ≤ 20%, 식량 0, 보스 등장
2. **분기 선택** — NPC 대화 / 가게 / 신전 선택지 (입력 필수)
3. **예상치 못한 적** — FOV에 보스 출현
4. **시야 외곽** — 시야 안 닿는 구역 항목 발견 (스탠스 셀로 가리키기)
5. **제안된 행동 모호** — 가장 가까운 적이 같은 거리 2개 동시일 때
6. **세이브 포인트** — 5층 마다 자동 저장
7. **시간 제한** — 풀자동에서도 1초마다 1회 멈춤 (`p`로 해제 가능)

### 자동 행동 우선순위 (디시전 트리, depth=2)

```
펼침: 우선순위 결정 트리

(Depth 0)
├── 시야 내 적? ──yes──> (1) 도달 가능한 적?
│                          │                    ├── 도달 가능 → (1.1) 이동
│                          │                    └── 불가 → (1.2) (안전 회복)
│                          └── 안전 거리 후퇴 가능 → 후퇴
├── 보스? ──yes──> (2) 보스 패턴 단계?
│                    ├── phase 1 → 공격
│                    └── phase 2 (유예 단계) → 회복
├── HP/MP 임계? ──yes──> 회복 (물약 > 신전)
├── 시야 내 아이템? ──yes──> 이동 (겹치지 않으면)
└── 미발견 구역? ──yes──> 탐색 (가장 가까운)
```

### UI 표기

- **상태 헤더 우측에 ` [A:페르소나] ` 또는 ` [수동] ` 같은 표기**로 모드 한눈에 보임
- **자동행동 발생 시마다 `→` 한 글자만 메인 메시지 한 줄** ("→쥐에게 5 피해" 식)
- **모호한 결정** 시 입력 모달 (1-2줄): "① 복도 따라 이동 / ② 회복 / ③ 멈춤 — 선택 [1/2/3]"

### 멀티태스킹 기능

#### A. 게임 속도 (볼륨 슬라이더)
- `+` / `-` 키 — 자동모드 진행 속도 0.5× ~ 4× (프레임 time)
- 기본 1×, 4× 시 시각적 강조만 표시 (스킵 옵션)

#### B. 자동 세이브 & 백그라운드 실행
- 매 액션마다 인메모리 + 매 30초마다 디스크 저장
- 디스크 저장 = JSON 스트림 (RON과 호환)
- 백그라운드 실행 시 세이브 파일은 자동 갱신

#### C. 메타 상태 (배지)
- 자동 진행 중에도 보이도록 가장 위 1줄에 항상 표시
- "🎮 23F HP 12/52 | MP 8/25 | 자동-연금술 | λ=2.0× | 12:55:23"

### 페르소나 데이터 모델 (1파일당 50~100 LOC)

```rust
struct Persona {
    name: &'static str,
    priority: Vec<PersonaRule>,
}

enum PersonaRule {
    AttackClosest,
    AttackWeakest,
    HealIfBelow { threshold: f32, target: HealPriority },
    CastIfMpAbove { threshold: i32, spell_picker: SpellPriority },
    Patrol,
    FleeIfHurtAt { threshold: f32 },
}
```

9개 페르소나 정의 + 게임 시작 시 1개 활성. 페르소나 메타 진행으로 잠금 해제 가능:
- 1회 클리어 → `무적`, `수호자`
- 10층 클리어 → `기습자`, `사냥꾼`
- 20층 클리어 → `연금술`, `마법사`
- 28층 클리어 → `순찰자`, `달인`, `신비`

### 자동 진행의 명시적 한계

| 자동 가능 | **자동 불가능** |
|---|---|
| 전투, 이동, 회복, FOV 탐색 | 학습 단계 선택 (스킬 트리 활성화) |
| 아이템 줍기 / 사용 | 신전 가게 / NPC 분기 선택 |
| 5층 보스전 (보스 약화 50%+ 시) | 인벤토리 직접 편집 |
| 영구 메타 적용 (런 종료 후) | 메타 화면 직접 조작 |

→ **자동이 가능한데 자동 안 되는 경우**는 디폴트 '잠시 멈춤'으로 가정.

## 20. 🤝 자동모드와 Spire-like 노브 (Knob) 결합

자동모드 + Roguelike 게임의 가장 큰 문제: **"자동이 잘 만들면 플레이어가 손 놓는다"**. 그래서 **노브 시스템** 도입.

### 노브란?
플레이어가 매 런 시작마다 **10-15 노브 슬라이더**를 조정 → 게임 룰을 미세 조정. 자동모드와 결합하면 **자기만의 게임 루프**가 만들어짐.

| 노브 | 디폴트 | 영향 |
|---|---|---|
| `hp.start` | 100 | 시작 HP |
| `mp.start` | 50 | 시작 MP |
| `food.start` | 8 | 시작 식량 |
| `enemy.speed_mul` | 1.0 | 적 속도 |
| `enemy.hp_mul` | 1.0 | 적 HP |
| `enemy.atk_mul` | 1.0 | 적 공격 |
| `vision.range` | 8 | 시작 시야 |
| `scaling.floor` | 1.0 | 층대당 스케일 |
| `autopilot.mode` | FullAuto | 자동 모드 |
| `autopilot.speed` | 2.0× | 자동 속도 |
| `pacing.recovery` | 1.0 | 회복 빈도 |
| `relic.density` | 1.0 | 유물 발견 |
| `gold.density` | 1.0 | 금화 발견 |
| `monster.density` | 1.0 | 적 밀도 |
| `trap.density` | 1.0 | 함정 밀도 |

### 프리셋 4종 (사용자가 직접 만든 조합 저장 가능)

- **기본** — 모든 값 1.0
- **제로 모드** — 적 HP 0.1, 적 공격 0.1, 자동 + 사냥꾼, 식량 × 2
- **하드 모어** — 적 HP 2.0, 적 공격 2.0, 보스 강화, 반자동만, 식량 0.5
- **관찰자 모드** — 적 HP 1.0, 적 공격 0.0, 자동 + 마법사, MP 5.0

### 노브와 영혼 시스템 결합

- **챔피언 영혼** + **노브 슬라이더** = 게임 룰의 두 축
- 한 방향은 강함 누적(**§18 영혼**), 다른 방향은 게임 룰 조정(**§20 노브**)
- 매 런 시작 시 (챔피언 × 노브) = 게임 상태 결정
- "챔피언: 마법사 + 노브: 마법사 강화 (MP +50%, 주문력 +1) + 자동 신비" 같은 빌드 가능

### 노브 슬라이더 UI (런 시작 화면)

```
┌─────── 신규 런 설정 ────────────────────────┐
│ Class: 마법사    Race: 인간                  │
│ Persona: [신비 ▼]    Mode: [F-Auto ▼]       │
│                                              │
│ 자동 슬라이더:                                │
│ 자동속도  ──────●────── 2.0×                 │
│ 회복빈도  ──●──────── 1.0                    │
│ 적 HP     ────────●── 1.0                    │
│ 적 공격   ────●────── 0.7                    │
│ 유물 발견 ─────●───── 1.5                    │
│                                              │
│ 챔피언 (5개 보유):                           │
│ [✓] 마법사 +시작 물약 1                      │
│ [✓] 인간 +시작 식량 +3                       │
│ [ ] 사냥꾼 +시작 활 1                         │
│                                              │
│ [ 시작하기 ]  [ 저장 슬롯 ]  [ 뒤로 ]         │
└──────────────────────────────────────────────┘
```

→ **자동모드 (§19) + 노브 시스템 (§20) + 영혼 (§18)**이 한 화면에서 합쳐짐. Roguelike 게임의 **"내가 만드는 게임 루프"** 컨셉.
